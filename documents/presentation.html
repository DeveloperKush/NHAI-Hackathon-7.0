Anti-Spoofing

Multi-Factor 3D Liveness

Four independent checks defeat photos, videos, and masks

👁️ Eye Aspect Ratio (EAR)

Real-time blink detection — threshold < 0.33

↔️ Head Yaw Assessment

Smoothed asymmetry detection with hysteresis (ON: 0.12, OFF: 0.09)

📐 3D Depth Verification

Z-coordinate std dev separates 3D faces from flat 2D screens

🎲 Random Challenge Order

Shuffled per session — unpredictable for attackers

Recognition

GhostFaceNet INT8 Engine

Desktop-grade accuracy in a 1 MB on-device model

// Recognition Pipeline
capture → 3-shot average (180ms apart)
preprocess → 5-point face alignment (112×112)
lighting → CLAHE / histogram equalization
inference → model.runSync() via JSI
output → 512-dim L2-normalized embedding
match → cosine similarity vs encrypted DB

// Thresholds
single_user: 0.75 | multi_user: 0.84
high_confidence: 0.91 | margin: 0.05
