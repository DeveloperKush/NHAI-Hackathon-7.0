# Binary Brains — Hackathon 7.0 Context
## 1. Project Identity
- Name: binary-brains-datalake
- Stack: Expo SDK 50 + React Native 0.73 + TypeScript strict
- Platforms: Android 8+, iOS 12+
- Constraint: 100% open-source (Apache 2.0 / MIT / BSD)

## 2. Architecture Snapshot
Pipeline: Camera → MediaPipe Face Mesh (liveness) → JPEG Decode (jpeg-js) → CLAHE/Align → GhostFaceNet INT8 (512-d) → Cosine Match SQLite → Log → AWS Sync

## 3. Interface Contracts (Stable)
### Types (src/types/index.ts)
- AuthLog: { log_id: string, user_id: string, timestamp: string, gps_lat: number | null, gps_lng: number | null, device_id: string, similarity_score: number, photo_thumb: string }
- LivenessErrorCode: 'TIMEOUT' | 'SPOOF_DETECTED' | 'NO_FACE_DETECTED'
- LivenessError: { code: LivenessErrorCode, message: string }
- FaceAuthenticatorProps: { onAuthSuccess: (log: AuthLog) => void, onLivenessFailed: (err: LivenessError) => void, onEnrollmentRequired: () => void, similarityThreshold?: number }

### Database & Encryption (src/services/database/ & src/services/encryption/)

  - executeSql(sql: string, params?: any[]): Promise<any>
  - initDatabase(): Promise<void>
- secureStorage.ts:
  - getOrCreateEncryptionKey(): Promise<string>

  - decryptData(cipherText: string): string
- enrolledFaces.ts:
  - insertEnrolledFace(user_id: string, embedding: Float32Array): Promise<void>
  - getAllEnrolledFaces(): Promise<{user_id: string, embedding: Float32Array}[]>

- authLogs.ts:

### Network & Sync (src/services/network/ & src/hooks/)
- awsSync.ts:
  - syncAuthLogs(): Promise<boolean> — returns true only on HTTP 200 + received_logs.
  - triggerSyncOnConnect(): listens to netinfo CONNECTED, calls syncAuthLogs()
- connectionInfo.ts:
  - useNetworkStatus(): returns { isConnected: boolean, connectionType: string }

### Image Preprocessing & Math (src/utils/)
- imagePreProc.ts:
  - applyCLAHE(imageData: Uint8Array, width: number, height: number): Uint8Array — enhances local contrast in 8x8 tiles.
  - globalHistogramEqualization(imageData: Uint8Array): Uint8Array — performs global equalization.
  - normalizePixels(imageData: Uint8Array): Float32Array — maps [0, 255] to [-1.0, 1.0].
  - cropTo112x112(imageData: Uint8Array, faceBoundingBox: { x: number; y: number; w: number; h: number }, originalWidth: number, originalHeight: number): Float32Array — crops & resizes using bilinear interpolation.
- math.ts:
  - cosineSimilarity(a: Float32Array, b: Float32Array): number — dot(a, b) / (norm(a) * norm(b)).
  - l2Normalize(vec: Float32Array): Float32Array — normalizes vector to unit L2 norm.

### Liveness Detection (src/services/ai/liveness.ts)
- calculateEAR(leftEye: Landmark[], rightEye: Landmark[]): number
- calculateMAR(lips: Landmark[]): number
- calculateHeadYaw(nose: Landmark, leftCheek: Landmark, rightCheek: Landmark): number
- checkDepthConsistency(landmarks: Landmark[], threshold?: number): boolean
- getPromptForState(state: LivenessState): string | null
- LivenessEngine:
  - processFrame(landmarks: Landmark[]): { state: LivenessState, prompt: string | null }
  - States: 'READY' | 'WAITING_BLINK' | 'WAITING_SMILE' | 'WAITING_HEAD_TURN' | 'PASSED' | 'FAILED'
  - Timeout: active challenges fail after 10s of inactivity.
  - Random challenge order determined at initialization.
  - Passive 3D depth check runs on every frame.

### Face Recognition (src/services/ai/recognition.ts)
- initRecognitionModel(): Promise<void> — Loads GhostFaceNet model into memory.
- getModelStatus(): { loaded: boolean; error: string | null }
- extractEmbedding(imageData: Float32Array): Float32Array (512-d, normalized, INT8 quantized/dequantized)
- findBestMatch(embedding: Float32Array, enrolledFaces: {user_id: string; embedding: Float32Array}[]): {user_id: string | null; score: number}
- averageEmbeddings(embeddings: Float32Array[]): Float32Array
- generateDeviceId(): string

### Camera Integration & Processing (src/services/camera/frameProcessors.ts)
- processCameraFrame(frame: CameraCapturedPicture): Promise<Float32Array> — decode JPEG via jpeg-js, convert to grayscale, resize, CLAHE, normalize
- simulateLandmarksFromFrame(frame: any, isRealFace: boolean): Landmark[] — generates 468 landmarks (real z-variance or flat spoof)
- captureEnrollmentFrames(cameraRef: any, count?: number): Promise<string[]> — captures snapshots sequentially, returns base64 JPEG array

### UI Components (src/components/)
- CameraOverlayProps: { cameraRef: React.RefObject<any>, status: LivenessState, children?: React.ReactNode }
- LivenessFeedbackProps: { message: string, type: 'success' | 'error' | 'warning', onDismiss?: () => void }
- FaceAuthenticatorProps: { onAuthSuccess: (log: AuthLog) => void, onLivenessFailed: (err: LivenessError) => void, onEnrollmentRequired: () => void, similarityThreshold?: number }
- Color Tokens: Primary=#1a237e, Background=#ffffff, Surface=#f5f5f5, Success=#4caf50, Error=#f44336, Warning=#ff9800, TextPrimary=#212121, TextSecondary=#757575
- Enrollment flow — capture 3-5 frames, average embeddings, insertEnrolledFace.

### Main Application & Demo (src/screens/ & src/App.tsx)
- Stack Navigation: DemoAuthScreen (initial), EnrollmentScreen stack entry.
- useNetworkStatus global listener in App.tsx: auto-sync triggers on CONNECTED network state.
- DemoAuthScreen layout: embeds FaceAuthenticator, scrollable recent logs from SQLite, detailed success card displaying nullable GPS, similarity score and time, and network-aware manual Sync Now button.


### Mock Server Contract (mock-aws-server/server.js)
- Endpoint: POST /api/sync
- Request: { logs: AuthLog[] }
- Success (HTTP 200): { message: "Batch synced successfully", received_logs: string[] }
- Purge rule: client deletes local logs ONLY after HTTP 200; retains queue on 4xx/5xx
- Idempotency: duplicate log_ids are acknowledged but not reprocessed
