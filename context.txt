# Binary Brains — Hackathon 7.0 Context
## 1. Project Identity
- Name: binary-brains-datalake
- Stack: Expo SDK 50 + React Native 0.73 + TypeScript strict
- Platforms: Android 8+, iOS 12+
- Constraint: 100% open-source (Apache 2.0 / MIT / BSD)

## 2. Architecture Snapshot
Pipeline: Camera → MediaPipe Face Mesh (liveness) → CLAHE/Align → MobileFaceNet INT8 (512-d) → Cosine Match SQLite → Log → AWS Sync

## 3. Interface Contracts (Stable)
### Types (src/types/index.ts)
- AuthLog: { log_id: string, user_id: string, timestamp: string, gps_lat: number | null, gps_lng: number | null, device_id: string, similarity_score: number, photo_thumb: string }
- LivenessErrorCode: 'TIMEOUT' | 'SPOOF_DETECTED' | 'NO_FACE_DETECTED'
- LivenessError: { code: LivenessErrorCode, message: string }
- FaceAuthenticatorProps: { onAuthSuccess: (log: AuthLog) => void, onLivenessFailed: (err: LivenessError) => void, onEnrollmentRequired: () => void, similarityThreshold?: number }

### Config (src/constants/config.ts)
- SIMILARITY_THRESHOLD = 0.6

### Liveness (src/constants/liveness.ts)
- Challenge: enum { BLINK, SMILE, HEAD_TURN }

- LIVENESS_THRESHOLDS = { EAR: 0.2, MAR: 0.6, headYaw: 0.15 }

### Database & Encryption (src/services/database/ & src/services/encryption/)
- sqlite.ts:
  - executeSql(sql: string, params?: any[]): Promise<any>
  - initDatabase(): Promise<void>
- secureStorage.ts:
  - getOrCreateEncryptionKey(): Promise<string>
  - encryptData(plainText: string): string
  - decryptData(cipherText: string): string
- enrolledFaces.ts:
  - insertEnrolledFace(user_id: string, embedding: Float32Array): Promise<void>
  - getAllEnrolledFaces(): Promise<{user_id: string, embedding: Float32Array}[]>
  - deleteEnrolledFace(user_id: string): Promise<void>
- authLogs.ts:
  - insertAuthLog(log: AuthLog): Promise<void>
  - getUnsyncedLogs(): Promise<AuthLog[]>
  - deleteSyncedLogs(log_ids: string[]): Promise<void>

- Sync Purge Rule: NEVER delete local rows until HTTP 200 confirmed
