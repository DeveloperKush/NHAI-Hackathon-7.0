# Binary Brains — Hackathon 7.0 Context
## 1. Project Identity
- Name: binary-brains-datalake
- Stack: Expo SDK 50 + React Native 0.73 + TypeScript strict
- Platforms: Android 8+, iOS 12+
- Constraint: 100% open-source (Apache 2.0 / MIT / BSD)

## 2. Architecture Snapshot
Pipeline: Camera → MediaPipe Face Mesh (liveness) → CLAHE/Align → MobileFaceNet INT8 (512-d) → Cosine Match SQLite → Log → AWS Sync

## 3. Interface Contracts (Stable)

- LivenessErrorCode: 'TIMEOUT' | 'SPOOF_DETECTED' | 'NO_FACE_DETECTED'

## 5. Key Decisions Log
- MVP Integration: Option A (expo-camera + deterministic embeddings until .tflite bundled)
- Database: expo-sqlite (upgrade to op-sqlite for production)
- Sync Purge Rule: NEVER delete local rows until HTTP 200 confirmed
- Encryption: AES-256 via react-native-encrypted-storage
- Phase 0 complete. Expo SDK 50 scaffold with all placeholder files. Strict TypeScript enabled.

## 6. Pending Risks
- MediaPipe WASM may be slow on iOS 12 → upgrade to react-native-fast-tflite (Option B) post-MVP
- INT8 model not yet bundled → using deterministic pseudo-embeddings for MVP
